How settlement will work

a row settles only when the official scoreboard prints the game Final and the game book's quarter scores sum to the printed final for both teams; a blocked row keeps both readings on the page and is not settled. When a sealed game's official final is available, a SETTLE entry is appended that records the final, the source URL, the model's favoured side, whether that side won, the absolute margin error in points, and a stamp — and it links back to the publish entry's hash, so the grade cannot be edited without breaking the chain.

Reproduce it: python3 d1b96315/ledger.py verify (read-only, writes d1b96315/data/ledger_check.json, which is what this page renders). publish and settle are deliberately not run by CI: a chain that CI re-appends on every push is not evidence.
