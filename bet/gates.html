The order, and why it is code

G1 pre-registered → G2 sealed before tip → G3 signal present → G4 validated → G5 settled only from a verified final. Each is a function call in scripts/publish_picks.py; a failure writes a row here and publishes nothing. The order matters: a validated pick sealed after tip is worthless, and a pre-registered pick settled from an unverified final is worse than worthless.

Freshness and provenance gates are on the projection surface's Gates page and must pass before either surface is built.
