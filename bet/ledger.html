What the chain does and does not prove

It proves that no stored pick, entry or link has been edited since it was written, to anyone who can see the file. It does not prove when it was written: anyone able to rewrite the whole file could rebuild the chain. The weak but real external witness is that the ledger is committed to git, so each build's commit hash fixes the head hash in a history this repository cannot quietly rewrite.

Tamper tests

Attempt Outcome Why
A published pick is edited after publicationDetectedverify() recomputes sha256(pick) and compares to the published value
An entry's contents are changedDetectedentry_hash no longer recomputes from its own body
An entry is removed or reorderedDetectedprev_hash no longer matches the preceding entry
A settled pick differs from the published pickDetectedthe settlement entry repeats pick_sha256_at_publish

These four cases are covered by tests/test_ledger.py, which builds a temporary ledger, breaks it deliberately, and asserts that verification fails. A verification routine that has never been shown to fail proves nothing.
