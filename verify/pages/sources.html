Sources

Every source used on this site, with the date it was read, what it supports and what it does not support. Sources marked OFFICIAL are operated by the league or a regulator. Sources marked TRUSTED-2 are reputable but not official, and every claim resting on one is labelled accordingly.

A value is only marked VERIFIED against an OFFICIAL source. Numbers recomputed from repository artefacts are marked VERIFIED-RECOMPUTED and do not depend on any external source.
This sandbox has no outbound network from the shell, so every page below was read with the fetch tool rather than curl. Fetch failures are recorded rather than hidden.
