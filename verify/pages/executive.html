Executive summary

What the repository establishes, what it contradicts, and what has to be decided. Written to be read in five minutes.

The one thing that is solid. Two sessions captured the 2026-27 season independently, from different sources, with different code. They agree on all 174 games: same dates, same teams, same exact final scores, same 9 overtime games. That log is trustworthy and it is the foundation everything else should be built on.
The one thing that is not. The repository publishes six dashboards that answer the same questions differently. This session found 9 contradictions. Two are outright defects: a parlay price function that silently returned the wrong quantity for every input, and every pick card naming the wrong side of the market. Both are fixed and covered by tests, but they were live on a public GitHub Pages site.

What the numbers do not support

  • No strategy is proven. Zero of eight pass all gates. The two best candidates rest on 24 and 28 bets against a 100-bet floor, so they are noise candidates, not signals.
  • No profit figure is real. Every ROI in the repository is measured against an assumed flat -110 price. For the moneyline strategies that price was never available, and for everything else no market price was ever recorded. The best published "edge" (+48% ROI) is an artefact of pricing a moneyline bet as a spread bet.
  • No injury effect has been modelled. The official report states availability, not minutes. The repository has no player game logs, so any minutes number would be invented. None is published.
  • No line has been compared to a bookmaker. "Originated lines" here are naive estimates that beat their own baseline. A model can beat a weak baseline and still be far behind the market.

Recommendation

Do not add another model. The repository already has six. The highest-value next step is to pick one dashboard, one gate set and one price source, mark the other five as archived, and start a prospective ledger. Until a price is recorded before tip-off and settled by an official source, no amount of modelling can distinguish skill from luck — which is exactly the distinction the brief asks for.
