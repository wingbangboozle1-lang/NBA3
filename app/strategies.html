What each gate is protecting against

Gate What it protects against
G1 Provenance A number with no source cannot be audited, so it cannot be trusted.repo
G2 Look-ahead The single most common way a backtest invents an edge. Ratings are refitted for every date from strictly earlier games; games are batched by date so a game cannot see another game tipped off the same night.repo
G3 Sample size Small samples produce large apparent edges. n ≥ 100 is a convention, not a measurement — see CQ-38.repo
G4 Power A rule can be 'not significant' simply because it was never able to detect the effect it found. This gate asks whether the observed effect is big enough for the sample to have seen it.repo
G5 Significance Exact two-sided binomial against the fair-line rate for that market.repo
G6 Multiple testing Fifteen rules at p < 0.05 produce a false positive more often than not. Benjamini–Hochberg controls the false discovery rate.repo
G7 Stability An effect that only exists in one half of the sample is usually a regime change, not a signal.repo
G8 Economics A date-block bootstrap of return at an assumed −110. Flagged: this is return against our own line, not profit — see NF-55.repo
G9 Luck threshold The board-level test. Even with G6, the single best-looking rule on a large board is biased upward. This gate asks whether the rule beats what the whole board produces by chance.repo

What is not on the board yet

Two gates this project thinks it needs and has not built: G10 pre-registration (hash the rule text and freeze it before the first graded forecast, so a rule cannot be written after seeing the results) and G11 price reality (every bet must be gradeable at a recorded, licensed price). Both are on the suggestions page as CS-31 and in CQ-37. Until G10 exists, treat every rule here as retrospective.
