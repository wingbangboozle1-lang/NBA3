S1 · Edge Single (moneyline/spread) PAPER

Originate a fair line for every slate game from official team strength (net rating proxy = PTS - OPPG), rest days, and injury production-at-risk. Bet only when our line diverges from a neutral baseline by >= edge_threshold and model confidence passes gates. One unit flat stake.

S2 · Correlated Double PAPER

Two S1 legs from the SAME game (e.g., favourite cover + over). Uses joint probability with computed correlation instead of naive independence. Only released when joint edge >= parlay_edge_threshold and leg correlation is measured, not assumed.

S4 · Rest/Fatigue Favourite PAPER

Subset of S1: only games where rest differential >= 2 days (opponent on back-to-back or 0-1 rest vs our side >= 2). Hypothesis: rest edges persist in the first month of the season. Uses only official schedule-derived rest values.
