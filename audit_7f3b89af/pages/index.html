How to reproduce this

  1. python3 audit_7f3b89af/capture.py — writes the verbatim captures of the four injury reports, the slate and the team statistics, from the tuples transcribed in capture.py.
  2. python3 audit_7f3b89af/checks.py — runs the 15 checks and writes data/verification_report.json.
  3. python3 audit_7f3b89af/analysis.py — the rest analysis, seed 20261114, writes data/analysis.json.
  4. python3 audit_7f3b89af/build.py — regenerates these pages.
  5. python3 -m unittest discover -s audit_7f3b89af -p 'test_*.py' — asserts the counts, the page rules and determinism.

Steps 1–4 run in CI on every push. The captures are transcriptions of pages that were read by hand, so they cannot be re-fetched by CI; they are stored as source code in capture.py precisely so they can be re-read and checked by a person.
