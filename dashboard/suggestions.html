Suggested discovery steps for the missing information

  1. Settle the rights question first (SG-01). One written decision on whether NBA data may be used for the intended purpose determines whether the rest of this project is research or something that needs a licence.
  2. Then the feed question (SG-02). Without timestamped prices, no economic claim is possible, and the leaderboard can only score calibration.
  3. Then close the data gaps (SG-03, SG-04). Per-player game logs unlock three blank correlation rows and every prop distribution. The full minutes table turns minutes-vacuum floors into real figures.
  4. Then fix the model (SG-05). A totals model that loses to a naive baseline should not be published as a betting signal.
  5. Then the operating rules (SG-12, SG-13, SG-14). Model register, cut-off and staleness rules, and settlement rules — before anything is scored as a result.
  6. Meanwhile, clean up the site (SG-08, SG-09, SG-10, SG-11). One dashboard, one deploy mechanism, a licence, and no non-official data files.
