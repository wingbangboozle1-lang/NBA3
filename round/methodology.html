The rules this build obeys

These are enforced by code and re-checked by tests, not just written down. Each one exists because breaking it produces a number that looks plausible and is wrong.

Data rules

  1. No value without a document. Every published row carries an https link to the official document it came from. The build refuses a row that does not.
  2. No inference. A cell the document does not print stays null. The one injury row whose status cell is missing is published null, not copied from the previous report.
  3. No repair of an official document. Where ATL@MIL's game book contradicts itself, both readings are kept and the row is published unsettled.
  4. Carried cells are recorded. When a table continues across a page break, the cell is carried from the printed row above and the carry is written onto the row with its evidence.

Gate rules

  1. Rebuild only after the gates pass. Freshness and provenance gates have build scope: if one fails, nothing is rebuilt and the site keeps its last good state.
  2. Integrity gates have row scope. A contradictory game book withholds its own row, with the failed arithmetic shown, and does not blind the reader to everything else.
  3. Freshness is measured against the official index, not against the file on disk. The gate compares the newest report the league lists with the one the build parsed.

Model rules

  1. Two estimators, no shared input. The disagreement is the headline; the blend is underneath.
  2. Home court is pinned to the measured home-win rate, not fitted freely.
  3. The total is possessions × points-per-possession, with the naive sum printed beside it.
  4. Luck is a z-score, and a strategy leaning on a team outside ±2 is not published.
  5. Shrinkage is chosen on past games only, by leave-one-game-out, never on the games being forecast.
  6. Both parlay prices are printed. The naive product and the price implied by the measured ρ.
  7. Nothing is invented when the input is absent. No closing line means no market anchor; no per-player logs means no prop rho.

The market-anchored prior, ready to switch on

The brief asks for the model line to be blended with the closing line, weighted by measured out-of-sample log-loss:

blended = w · model + (1 − w) · closing,   w = exp(−LL_model) / (exp(−LL_model) + exp(−LL_closing))

The formula is implemented; the weight is null because there is no closing line to measure LL_closing from. Filling it with a chosen weight would be the invented number this project refuses to print.
