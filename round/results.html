Official finals, 2026-11-15

One row per game: date, teams, final score, and all four (or five) quarter scores. Each row is read from that game's official game book and cross-checked against the game book's own recap line and the official scoreboard.

ATL@MIL is published unsettled. The game book's SCORE BY PERIOD table prints Milwaukee's third quarter as 37, which makes their quarters sum to 116 against a printed final of 106. The same document's recap line prints 27 in that quarter, which does sum to 106. Both readings are kept in the data, the arithmetic is printed on the row, and the row is not settled. Choosing whichever line parsed first would be a silent repair of an official document; this build does not do that.
Settlement stamp. A settled row carries the instant it was confirmed against the official document. The stamp moves only when the official values are re-read, so a stale stamp is visible as stale rather than being refreshed by a rebuild.
