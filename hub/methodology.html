How a line is originated

  1. Every input is read from an official NBA source: the teams-advanced table for the ratings, the schedule for the slate, the official injury report for availability, and the official player table for minutes.
  2. The margin line is the blend of two estimators (additive points form and a Massey least-squares rating form), fitted on the verified results only: LM-C blend (A+B margins, T2 total).
  3. The total line is the own-scoring estimator: LM-B Massey least-squares margin model, which the walk-forward test shows does not beat the league-average baseline. That is published, not hidden.
  4. Home-court advantage is added as a fitted constant (1.59 points) even though its p-value is 0.1045; the least-squares estimate is used and the uncertainty is stated.
  5. Lines are produced for every game in the window, including games where the injury report has not been submitted; availability is shown separately rather than being folded silently into the number.

How luck is removed

  • No look-ahead. Each game is predicted only from games that had already been played. The first 30 games are burned in.
  • Exact binomial test of the hit rate against the strategy's own null, with a Benjamini-Hochberg correction across the strategy family so that testing many strategies does not manufacture a winner.
  • Minimum sample and power gates. A strategy below 100 observations fails G3, and G4 asks whether the observed effect would be detected with 80% power at that sample size.
  • Split-half stability. The effect must point the same way in the first and second half of the sample.
  • Provenance and calibration gates. Every input must be official or derived from official data, the model must be calibrated on held-out games, and the fair price must survive de-vigging.
  • Independent replication. A second, separately built engine in this repository tests its own strategies with its own gates; its results are published next to the first engine's.

What is measured and what is assumed

Measured from official data
Team ratings, pace, the verified game log, availability and minutes, the walk-forward predictions, the hit rates, the correlations.
Assumed
Independence between legs of a cross-game parlay; that the league average is a valid baseline for a total; that the captured top-31 minutes set represents each rotation; that season averages are a reasonable prior for a single game.
Never estimated
Player-level correlations, points impact of an injury, expected value against any market price, and every value that could not be confirmed against an official source.

Reproducing this dashboard

python3 scripts/build_hub_data.py    # merge verified sources -> data/hub/dashboard.json
python3 scripts/build_hub.py          # render hub/*.html
python3 scripts/build_hub.py --check  # validate links and sources, write nothing

Standard library only. The upstream artefacts are regenerated by python3 model/build.py (origination engine), python3 pipeline/build_site_data.py (Edge Lab) and the generators behind the earlier trees.
