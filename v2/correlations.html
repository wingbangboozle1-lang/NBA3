Measured dependence and parlay prices.

Parlays are priced twice: the naive product, which assumes the legs are independent, and the copula price at the measured correlation. Both are always printed. Where a correlation cannot be measured, only the naive product is shown and it is labelled as an assumption.

What cannot be measured here

PairWhy not
player A points vs player B points, same team, same gameneeds per-player game logs for a full season; only 2 of 30 teams' top-8 minutes were captured and no game logs at all
player points vs player rebounds, same playerneeds per-player game logs
player points vs player assists, same playerneeds per-player game logs
player stat vs the same game's team totalneeds per-player game logs and would still be a small-sample estimate
leg A vs leg B across two different games on the same nightno shared state to correlate; measurable only as a null, and a null with no data behind it is not a measurement

A correlation inside its own confidence interval of zero is not zero. It is 'not distinguishable from zero at this n', which is a weaker and more accurate statement. The parlay prices use the point estimate and say so.
