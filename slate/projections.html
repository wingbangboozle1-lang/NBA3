How the blend weight is set

w_i = exp(-logloss_i) normalised; an estimator receives weight only once it has at least 30 out-of-sample games. Until then the measured estimator carries the blend and the weights are published with the sample sizes. Today: w(E1) = 1.000, w(E2) = 0.000 — E2's weight is 0 because the official efficiency page is a single current snapshot: it has produced one out-of-sample game so far. The blend therefore equals E1 today and the published headline is the disagreement, not the blend.

Home-court advantage is pinned, not fitted

HCA is pinned to the measured home-win rate, never fitted: HCA = sigma x probit(home_win_rate), where sigma is the standard deviation of the game margin (home - away) over the official log. Measured over 191 official finals: 101 home wins (0.5288), margin sigma 16.790 pts → HCA = 1.213 points.
