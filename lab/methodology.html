Method and validation gates

Every number on this site is either transcribed from a source, computed from transcribed numbers by the code in this repository, or explicitly marked as an assumption. This page is the audit trail for that claim.

The five verification tiers

TierMeaningHow it is used hereSource
OFFICIALOperated by the NBA Schedule, game IDs, venues, injury statuses, the reporting rule. Never used for a probabilistic claim, because the league does not publish one.this page
TRUSTED-2A reputable secondary source Team ratings (Basketball-Reference), game results, market prices (ESPN relaying one book). Always labelled, never described as official.this page
MARKETA live price from a book Spreads, totals, moneylines, prop prices. A price is a fact about the market at a timestamp, not a fact about the game.this page
DERIVEDArithmetic on the above Every modelled spread, total, probability, correlation and score. Formula shown on the page where it is used.this page
UNVERIFIEDNo source could confirm it Left blank, listed on Flagged for review. No value is ever inferred to fill the gap.review page

Origination model

For each team, from the advanced ratings table: shrunk_net = net_rating x (G / (G + k)) k = 11.0 Per matchup: pace = (pace_home + pace_away) / 2 home_pts = ORtg_home x (DRtg_away / 114.0) x (pace / 100) away_pts = ORtg_away x (DRtg_home / 114.0) x (pace / 100) margin_home = (home_pts - away_pts) + HCA model_spread = -margin_home (book sign convention) model_total = home_pts + away_pts Probabilities under a normal margin model: P(home win) = Phi(margin_home / sd_margin) P(home covers h) = Phi((margin_home + h) / sd_margin) h = listed home handicap P(over t) = 1 - Phi((t - model_total) / sd_total) De-vigging a two-way price: p_a = 1 / decimal_a ; p_b = 1 / decimal_b ; fair_a = p_a / (p_a + p_b)

The ratings are multiplicative rather than additive because a good offence meeting a bad defence should produce more points than the same two ratings meeting in the other order. Using only net ratings would throw that away.

The measured values above carry confidence intervals, and the assumed values carry this range on purpose. A point estimate presented without either is the thing this build is trying to avoid.

G4RobustnessWalk-forward holdout, multiple regimes, ablations, and enough sample that the result is not one hot streak?strategies page
G5DependenceFor combinations: is the joint probability modelled or measured directly, with the correlation and its uncertainty reported?strategies page
G6Economic testTimestamped prices, settlement rules, hold and execution assumptions, and net expected value with drawdown?strategies page
G7Prospective monitoringFrozen model version, pre-tip logged forecasts, post-settlement scoring, and drift detection?strategies page

A strategy must pass all seven to be eligible for the leaderboard's top tier. Current standing: no strategy passes all seven, and the leaderboard says so in every row.

How to reproduce this build

Nothing is hand-edited into the HTML. The site is generated, so a corrected input flows through to every page.
