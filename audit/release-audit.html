high		The canonical 'official capture' CI step is an offline hard-coded transcription check, not a live re-fetch.
The script contains static schedule, team-statistics, and injury-report constants and has no HTTP client import. Running it in CI checks the committed snapshot against those same constants; it cannot establish that a source is current or independently re-verify the transcription.		Repository evidenceOfficial reference
