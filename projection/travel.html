Rest, back-to-back and travel from a sourced table

The coordinate table, where each venue string comes from, and every measured distance.

Travel distance is now computed from a sourced coordinate table instead of being blank. The NBA publishes no arena latitude/longitude, so the coordinates come from the MediaWiki coordinates API and every distance is labelled reference, not official. The venue name comes from an official NBA page; the coordinate comes from the reference table; the distance is derived. The three are never mixed without saying so.

What was actually wrong, stated precisely. Two things, and a third that was not wrong:

  1. Wrong: the repository contradicted itself. data/live/rest_travel.json reported travel_unverified: 44 of 44 team-games, while app/projections.html printed numeric kilometres for the same team-games from a second source (data/app/estimators.json). One surface said "unverified", another printed it as a measurement.
  2. Wrong: the resolver keyed venues by city name, which is not a venue identity. It happens to give the right answer whenever both games are in the same city, and a silently wrong one as soon as a club changes building.
  3. Not wrong: the 0.0 km values. PHI, PHX and LAC each played at home in their previous game (verified against data/origin/games.csv), so zero is correct. My first draft of this finding called them an artefact; that was a mistake and it is corrected here and in the review log.

The new resolver takes a venue string and has no city parameter at all, which tests/test_travel_distance.py pins. The duplicate source of travel numbers is logged as change request CR-42-07.

What a distance here is, and is not

  • It is a great-circle distance between two arena coordinates, on R = 6,371.0088 km.
  • It is not an NBA figure, a road distance, or a measure of fatigue. No official NBA page publishes any of those.
  • It cannot be used as a model input until you decide whether a reference coordinate source is acceptable for that use — that is Q42-4.
Every number on this page is either copied from an official NBA page (linked) or derived and labelled as derived. Values that could not be confirmed are blank and listed on Flagged for review. Research, not betting advice. Source: https://github.com/wingbangboozle1-lang/NBA3.
