Open questions

What must be known before a decision, what each blocks, and what would answer it.

8 questions, all open. Each one names what it blocks and what would actually answer it. None is decided unilaterally here, because each changes what the site is allowed to claim.

The two that matter most. Q1 (a licensed closing line) decides whether this project can ever measure an edge, and Q2 (arena coordinates) decides whether travel is a real feature or a permanent blank. Everything else is recoverable; those two change the shape of the product.

How to discover missing information

The pattern that has worked in this session: name the column, then name the official page that would fill it, then check whether that page actually publishes it. Travel distance is the worked example — the column exists, the page does not publish coordinates, so the column stays blank and the gap is published as a question rather than filled with an estimate. The suggestions page proposes a capture step for each question whose answer is obtainable but not yet obtained.
