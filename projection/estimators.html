Estimators

Two models, one scoring rule. E1 uses margins, E2 uses only wins, and the gap between them is the published confidence signal.

Two estimators, deliberately built on different information, so that their disagreement carries meaning. Neither is "the model". Both are scored on the same walk-forward slate: each forecast uses only games that had already been played.

E2's shrink weight is not a free parameter. It is chosen by log-loss on the most recent 20% of past games (38 validation games), from a fixed grid of 8 values, and the choice comes out at 2.0. The scores are published on the bet surface's pre-registration page with the rest of the validation detail. An earlier build applied the same penalty on a points scale instead of a logit scale, which put it ~30× the information content of the data; that produced an out-of-sample log-loss of 0.64 with 600 non-converged iterations, and it is recorded here because it is the kind of error that flatters a model until it is scored.

Source for every HCA value on this page: nba.com/games (official finals). The rule is applied to the whole sample, so the values are one calculation, not one row each.

The naive fitted HCA (mean home margin) also absorbs any sample imbalance in team strength between home and away schedules. The pinned version uses only the home-win rate, so a schedule artefact cannot inflate it. Both are printed; the model uses the pinned one.
