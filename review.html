Flagged for Review

Integration audit · 14 November 2026 UTC · Findings below are not hidden by passing code checks.

Do not use the repository’s experimental picks, “positive EV” labels, fair prices, correlations or performance figures as betting recommendations. The repository has several distinct modeling workstreams with inconsistent inputs and results. This page records evidence and the information needed to resolve each issue. It does not claim that any published statistical output is true or profitable.

“Verified” here means an artifact or official source text was inspected for this audit; it does not mean the artifact’s underlying sporting data or model result has been independently validated.

Suggested order of work

  1. Legal/data rights review and intended-use decision.
  2. Choose one canonical pipeline and permissioned data source; archive or relabel duplicates.
  3. Reconcile raw data and independently verify values against official or licensed primary sources.
  4. Unify definitions, timestamped evaluation records, settlement rules and validation gates.
  5. Keep all output in research/paper mode until a prospective test supports any further decision.
